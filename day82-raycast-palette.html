The command palette — storing the selection as an index is why Enter sometimes runs the wrong command.

Type, and watch the score

A command palette matches subsequences, not substrings: typing gp should find Git: Push. Matched characters are bold below, and the score is the one the ranking actually sorts on.

QUERY

What each matched character is worth

The weights are the design. A letter at the start of a word is worth seven points; one adjacent to the previous match, five; a letter buried mid-string, barely one — and less the deeper it sits.

Seven queries against fifteen commands. zzz is there to show the empty case is a case.

The bug every palette has shipped at least once

The list changes on every keystroke. If the selection is stored as an index, row 3 of the old list becomes row 3 of a different list — and the next Enter runs a command the user never looked at.

The fix is one line: store the id, and fall back to the top only when that id is no longer in the list.

Scoring, and why the match is a DP rather than a scan

A greedy left-to-right matcher finds a match, not the best-scoring one. The difference shows up exactly on the queries people type: short initialisms over multi-word commands.
